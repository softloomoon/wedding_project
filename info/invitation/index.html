청첩장, 언제 누구에게 어떻게 돌릴까

웨딩 프로젝트 · 2026.11.25 · 약 4분

청첩장은 결혼 소식을 알리는 첫인사예요. 언제, 어떤 방식으로 전하느냐에 따라 받는 사람의 기분이 달라지기도 해요. 준비 시기부터 전하는 예절까지 정리했어요.

목차
  1. 언제 준비하고 언제 돌릴까?
  2. 누구에게, 어떤 방식으로?
  3. 청첩장에 꼭 들어갈 내용
  4. 모바일 청첩장 문구와 예절
  5. 돌린 뒤에 챙길 것

1언제 준비하고 언제 돌릴까?

  • 예식 3~2개월 전: 디자인을 고르고 하객 명단을 정리해 인쇄 수량을 정해요. 인쇄와 배송에 2~3주가 걸리기도 해요.
  • 예식 2~1개월 전: 직접 만나거나 우편으로 전해요. 가까운 사람일수록 일찍, 직접 전하는 게 좋아요.
  • 예식 한 달~2주 전: 모바일 청첩장을 보내요. 너무 이르면 잊히고, 너무 늦으면 일정을 비우기 어려워요.
  • 예식 1주 전: 참석하기로 한 분들께 장소와 시간을 한 번 더 알려 드리면 좋아요.

2누구에게, 어떤 방식으로?

  • 가족·은사·가까운 친구: 가능하면 만나서 직접 전해요. 식사 자리를 마련하는 경우가 많아요.
  • 어른들: 종이 청첩장을 우편이나 직접 전하는 게 예의로 여겨지는 경우가 많아요. 양가 부모님께 필요한 수량을 미리 여쭤 보세요.
  • 직장 동료: 회사 분위기에 맞춰 종이 청첩장을 돌리거나 팀 단위로 전해요.
  • 오래 연락하지 않은 사람: 모바일 청첩장만 불쑥 보내면 부담스러울 수 있어요. 안부 인사를 먼저 건네고, 부담 갖지 말라는 말을 함께 전하면 좋아요.

3청첩장에 꼭 들어갈 내용

  • 신랑·신부 이름 (필요하면 양가 부모님 성함)
  • 예식 날짜, 요일, 시간
  • 예식장 이름, 층과 홀 이름, 주소
  • 오시는 길: 대중교통, 주차 가능 여부와 시간
  • 모바일 청첩장이라면 지도 링크, 참석 여부 회신, 식사 안내

TIP 인쇄 전에 날짜와 요일, 홀 이름을 두 사람이 따로 한 번씩 확인하세요. 가장 많이 나는 실수예요.

4모바일 청첩장 문구와 예절

  • 첫 문장은 짧은 인사로 시작해요. 예: "오랜만이야, 잘 지냈지? 우리 결혼해! 와 주면 정말 기쁠 것 같아."
  • 단체방에 링크만 올리기보다 한 사람씩 보내는 게 마음이 전해져요.
  • 축의금 계좌는 넣을지 두 사람이 먼저 정하세요. 넣는다면 '마음 전하실 곳'처럼 부드럽게 쓰고, 기본 화면이 아닌 펼쳐 보는 곳에 두는 경우가 많아요.
  • 사진과 문구는 양가 부모님도 보신다는 생각으로 골라요.

5돌린 뒤에 챙길 것

  • 누구에게 언제 어떤 방식으로 전했는지 하객 명단에 표시해 두면 빠뜨리는 사람이 없어요.
  • 예식 후에는 와 주신 분, 축하를 전해 주신 분께 감사 인사를 전해요. 체크리스트의 '감사 인사' 항목도 함께 챙겨 보세요.

하객 명단이 정해졌다면? 예산표에서 식대와 답례품 비용도 함께 계산해 보세요.
